# Saleringo — vulnerability reporting

# file is the machine-readable form of the same statement, at the location a
# researcher's tooling looks first. It is the one piece of security evidence
# that can honestly be published rather than sent on request.
#
# The contact is the request form, not a mailbox: saleringo.com has no MX
# record yet, so mail to security@saleringo.com bounces. The form stores the
# report and a person reads it. When the mailbox exists it is added here.
